# الجدول الأسبوعي للمدارس المهنية — النشر + التفعيل الأونلاين

هذا المجلد جاهز للرفع على مستودع `Mahani` في GitHub ونشره عبر **GitHub Pages**.

روابطك بعد النشر:

| الصفحة | الرابط |
|---|---|
| التطبيق (للزبائن) | `https://hussainnahi1989-ctrl.github.io/Mahani/` |
| لوحة التحكم (لك فقط) | `https://hussainnahi1989-ctrl.github.io/Mahani/admin.html` |

---

## 1) محتويات المجلد

```
Mahani/
├── index.html            ← التطبيق (نسختك + التفعيل الأونلاين + PWA)
├── admin.html            ← لوحة التحكم الأونلاين (دخول بكلمة سر)
├── config.js             ← إعدادات Firebase (الملف الوحيد الذي تعدّله)
├── license-online.js     ← منطق التفعيل الأونلاين داخل التطبيق
├── sw.js                 ← Service Worker (يعمل أوفلاين + التثبيت)
├── manifest.webmanifest  ← بيانات التثبيت على الهاتف
├── offline.html          ← صفحة «لا يوجد إنترنت» للزيارة الأولى
├── firebase-rules.json   ← قواعد أمان قاعدة البيانات (تنسخها في Firebase)
├── icons/                ← أيقونات التطبيق
└── .nojekyll             ← يمنع معالجة Jekyll في GitHub Pages
```

## 2) إنشاء مشروع Firebase (مرة واحدة — ١٠ دقائق)

1. ادخل [console.firebase.google.com](https://console.firebase.google.com) بحساب Google ثم **Add project / إنشاء مشروع** (الاسم مثلاً `Mahani`).
2. من **Build ← Realtime Database** اضغط **Create Database**:
   - اختر موقعاً قريباً (مثل `europe-west1`) — **Next**
   - اختر **Start in locked mode** — **Enable**
3. من **Build ← Authentication ← Sign-in method** فعّل **Email/Password** ثم **Save**.
4. من **Authentication ← Users ← Add user** أنشئ حساباً لنفسك (بريدك وكلمة سر قوية) — هذا حساب دخولك للوحة التحكم.
5. من ⚙️ **Project settings ← General ← Your apps** اضغط `</>` (تطبيق ويب)، سمّه مثلاً `Mahani Web`، ثم انسخ قيم `firebaseConfig`.
6. افتح ملف **`config.js`** واستبدل القيم:

```js
firebase: {
  apiKey: "AIza........",
  authDomain: "mahani-xxxxx.firebaseapp.com",
  databaseURL: "https://mahani-xxxxx-default-rtdb.firebaseio.com",   // ← أهم سطر
  projectId: "mahani-xxxxx",
  ...
}
```

> ملاحظة: `databaseURL` يظهر في الأسفل داخل كائن firebaseConfig. إن لم يظهر، خذه من صفحة Realtime Database (أعلى الصفحة بجانب عنوان البيانات).

---

## 3) نشر قواعد الأمان

1. افتح **Realtime Database ← Rules**.
2. انسخ محتوى ملف **`firebase-rules.json`** والصقه.
3. افتح `admin.html` (بعد رفع الملفات أو محلياً عبر السيرفر) وسجّل الدخول، ثم انسخ **UID** الظاهر أعلى الصفحة.
4. في القواعد استبدل `ADMIN_UID_HERE` (موجود مرتين) بهذا الـ UID ثم **Publish**.

**ما تفعله هذه القواعد:**
- أي جهاز جديد يستطيع فقط إنشاء طلب بحالة `pending`، ولا يستطيع تفعيل نفسه.
- أنت وحدك (صاحب الـ UID) تقرأ كل الأجهزة وتغيّر حالتها.
- حجم الحقول ونوعها مفحوص لمنع العبث.

## 4) رفع الملفات على GitHub

**الطريقة الأسهل (بدون برامج):**
1. حمّل مجلد `Mahani` كملف مضغوط أو افتح ملفاته.
2. ادخل [github.com/hussainnahi1989-ctrl/Mahani](https://github.com/hussainnahi1989-ctrl/Mahani).
3. اضغط **Add file ← Upload files** واسحب كل الملفات والمجلدات (بما فيها `icons` وملف `.nojekyll`).
   > GitHub لا يعرض الملفات التي تبدأ بنقطة عند السحب أحياناً — إن لم يُرفع `.nojekyll` فلا مشكلة، وجوده اختياري.
4. اضغط **Commit changes**.

**أو عبر Git:**
```bash
git clone https://github.com/hussainnahi1989-ctrl/Mahani.git
cd Mahani
# انسخ محتويات مجلد Mahani هنا
git add -A
git commit -m "إطلاق التطبيق مع التفعيل الأونلاين"
git push origin main
```

## 5) تشغيل GitHub Pages

1. في المستودع: **Settings ← Pages**.
2. تحت **Source** اختر **Deploy from a branch**، والفرع `main` والمجلد `/ (root)` ثم **Save**.
3. انتظر دقيقة ثم افتح: `https://hussainnahi1989-ctrl.github.io/Mahani/`

## 6) كيف يستلم الزبون التفعيل؟

1. ترسل للزبون رابط التطبيق فقط.
2. يفتح الرابط → يضغط **📲 تثبيت التطبيق** (أندرويد: «تثبيت»، آيفون: مشاركة ↗ ← إضافة للشاشة الرئيسية).
3. بأول تشغيل يُسجّل التطبيق رمز جهازه تلقائياً في قاعدة البيانات كطلب **قيد الانتظار** — بدون أن يرسل لك شيئاً.
4. تفتح أنت `admin.html` وتسجل الدخول → ترى الطلب (اسم المدرسة، المدير، الهاتف، وقت الطلب) → تضغط **✓ تفعيل**.
5. التطبيق عند الزبون يكتشف التفعيل خلال ثوانٍ (٨ ثوان والنافذة مفتوحة، ٢٥ ثانية في الخلفية) ويفتح الميزات **تلقائياً بلا أي رمز**.
6. بعد التفعيل يعمل التطبيق **بدون إنترنت للأبد**. وإن ضغطت **🚫 إلغاء** من اللوحة، يُقفل عند أول اتصال له بالإنترنت.

**للزبون الذي لا يملك إنترنت نهائياً:** من اللوحة → قسم «مفتاح تفعيل يدوي» → الصق رمز جهازه → انسخ المفتاح وأرسله له. (هذا المفتاح مطابق تماماً لخوارزمية التطبيق الأصلية.)

## 7) استكشاف الأخطاء

| المشكلة | السبب والحل |
|---|---|
| اللوحة تكتب «تعذّر القراءة… permission denied» | لم تستبدل `ADMIN_UID_HERE` بالـ UID أو لم تضغط Publish |
| التطبيق يكتب «الخادم غير مُعدّ» | `databaseURL` في `config.js` ناقص أو غير صحيح |
| الزبون يظهر «طلب قيد الانتظار» ولا يُفعّل | تأكد أنك تفعّل نفس `appId` (`vts-professional-timetable`) في اللوحة |
| لا يظهر زر التثبيت | المتصفح لا يدعمه (افتح القائمة ⋮ ← تثبيت التطبيق) أو التطبيق مثبّت مسبقاً |
| التطبيق لا يفتح أوفلاين | يجب فتحه مرة واحدة وهو متصل بالإنترنت (مرة واحدة فقط) |
| تحديثاتك لا تظهر للزبون | اضغط تحديث الصفحة مرتين، أو غيّر رقم `VERSION` داخل `sw.js` |

## 8) ملاحظات أمنية

- **`apiKey` في `config.js` ليس سراً** — هو معرّف عام لتطبيق الويب. الحماية الحقيقية هي **قواعد الأمان** + حسابك في Authentication.
- لا تشارك رابط `admin.html` مع الزبائن؛ هو محمي بكلمة سر، لكن قواعد الأمان هي خط الدفاع الحقيقي.
- قراءة عقدة جهاز بعينه مسموحة للعموم (`".read": true`) حتى يستطيع التطبيق معرفة حالة تفعيله. من يعرف رمز الجهاز يمكنه رؤية اسم المدرسة والهاتف المسجل. إن أردت إخفاء ذلك تماماً فالحل هو Cloud Function — قل لي وأضيفه.
- احتفظ بنسخة من بياناتك: من Firebase Console ← Realtime Database ← ⋮ ← **Export JSON**.
